# Security

yourmove puts words into your coding agents' sessions as if you had typed them. A hole in it can
let someone steer an agent on your machine, so please report one privately.

## Reporting

Use GitHub's private vulnerability reporting: **Report a vulnerability** on this repo's Security
tab. Please don't open a public issue.

Say who the attacker is (a repo you cloned, a web page you visited, another account on the same
machine), the steps, and what they get.

## Scope

The README's [Security](README.md#security) section sets out what yourmove defends against:
boards you never trusted, forged or edited comments, other sites in your browser, and other
accounts on the same machine. Anything that lets one of them put words in a session, or read
or change the board through the server, is in scope.

## Supported versions

The latest release.
